# Add Explicit Focus Indicator Styles

## Overview

While hover and focus color changes exist for links, there are no explicit :focus outline or ring styles for interactive elements. This makes keyboard navigation difficult as users cannot clearly see which element has focus.

## Rationale

Accessible focus indicators are essential for keyboard users and users with motor disabilities who rely on keyboard navigation. Default browser outlines are often removed or insufficient. WCAG 2.1 requires visible focus indicators.
