# Add Gallery Call-to-Action Styles

## Overview

The .gallery-cta class is used in both the main gallery and photo gallery sections to encourage visitors to contact the artist, but it has no CSS styling defined.

## Rationale

The call-to-action is a critical conversion element - encouraging visitors to visit the atelier or contact the artist. Without distinctive styling, this important message blends in with regular content and loses its persuasive power.
