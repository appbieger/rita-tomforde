# Add Event Article Styling

## Overview

The .event class used in the Aktuelles (Current Events) section wraps individual event articles but has no CSS styling. Events contain important information about upcoming exhibitions.

## Rationale

Current events are time-sensitive and important for engaging visitors with the artist's activities. Properly styled event cards make this information scannable and help visitors quickly identify dates, locations, and times.
